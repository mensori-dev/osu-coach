# osu! Coach

Неофициальный тренер для osu! под Windows: смотрит живой плей через [tosu](https://tosu.app), читает твою локальную базу
(osu!.db и scores.db), показывает прогресс и говорит, что делать дальше. Без ИИ и без «магии» — все выводы считаются по
твоим же скорам.

> Не связан с osu! и ppy. osu! — торговая марка ppy Pty Ltd.

## Что умеет

- **Живой режим** — точность, комбо, pp, UR, прогресс карты и хит-ошибки в реальном времени.
- **Разборы** — последние 10 плеев с вердиктом, сравнением с твоим обычным уровнем и конкретным советом.
- **Разбор реплея** — кидаешь `.osr`, и прога находит карту в твоей базе и показывает, **где** сыпалось:
  на стримах или на джампах, в какие секунды, рано или поздно ты жал.
- **Прогресс** — точность по дням, ступени сложности, «ты здесь» и следующая цель в п.п. Видно, растёшь или стоишь.
- **План** — цели по навыкам и карты из твоей базы: что дожимать на чистоту, а где шагнуть выше комфорта.
- **Карты** — подбор новых карт под твой вкус (мапперы, артисты, темп, длина), превью трека и скачивание в один клик.
- **Разминка** — три карты на сегодня: разогрев, форма, выносливость.
- **Профиль** — факты о том, как ты играешь: комфорт, потолок, любимые мапперы и время суток.
- **Адаптивная тема** — цвета подстраиваются под обложку текущей карты.

Всё обновляется само: закончил карту — приложение перечитало базу и пересчитало цифры, без кнопок и перезапуска.

## Установка

1. Скачай `osu-coach-*-setup.exe` со [страницы релизов](../../releases/latest).
2. Запусти установщик. Права администратора не нужны.
3. Поставь [tosu](https://github.com/tosuapp/tosu/releases) — без него живой режим не работает.
4. Запусти osu! Coach, пройди короткий онбординг (можно пропустить).

Если osu! запущен от администратора, tosu тоже нужно запустить от администратора — иначе Windows не даст им общаться.

### Ключи osu! API (необязательно)

Без ключей работают живой режим, разборы, прогресс и локальный подбор карт. Ключи нужны для профиля с osu! и поиска
новых карт онлайн.

1. Открой https://osu.ppy.sh/home/account/edit#oauth и создай OAuth-клиент (Callback URL — любой, например
   `http://localhost`).
2. В приложении: **Настройки → Аккаунт osu!** — вставь client id и client secret и нажми «сохранить ключи».

Ключи хранятся только на твоём компьютере в `%APPDATA%\osu-coach\data\settings.json`. В репозиторий и в интернет они
не попадают: наружу уходят только запросы к официальному osu! API.

## Приватность

- Локальные данные читаются из папки osu! и никуда не отправляются.
- В сеть уходят только запросы к `osu.ppy.sh` (профиль и поиск карт) и `osu.direct` (скачивание карт).
- Никакой телеметрии, аккаунтов и облака.

## Сборка из исходников

Нужны Node.js 22+ и Windows.

```bash
npm install
npm run dev      # разработка
npm run check    # типы, линтер, формат
npm run dist     # установщик в release/
```

`.env` не обязателен. Если хочешь держать ключи в файле, скопируй `.env.example` в `.env`.

## Структура

- `src/main` — Electron main: чтение osu!, tosu, osu! API, скачивание карт, слежка за scores.db.
- `src/preload` — мост IPC.
- `src/renderer` — React-интерфейс.
- `build` — иконки и ресурсы установщика.
